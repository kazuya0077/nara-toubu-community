# 東部地域 暮らしの案内

公開サイト: https://kazuya0077.github.io/nara-toubu-community/about.html

公開サイトに必要なファイルのみを配置しています。main の更新で GitHub Actions からデプロイします。写真と投稿の端末保存は、オンラインへの公開とは別です。

## タイムラインのチラシ

タイムラインのお知らせ欄にある「市社協・包括などのチラシを追加する」から画像（JPEG・PNG・WebP）またはPDFを追加します。名前・発行元・種類・説明を入力してプレビューを確認し、「この端末に保存」で端末に保持できます。登録なしで閲覧・試用できます。オンラインでの投稿受付機能ではありません。

ほかの利用者にも公開する場合は「公開用ファイルを書き出す」で得た `flyers.js` を運営が確認し、`data/flyers.js` と差し替えてmainに反映します。チラシは12件、1件10MB、全体20MBまでです。不要なチラシを外して書き出すと、公開データからも除けます。「公開中のチラシに戻す」で端末のプレビューを解除します。発行元の許諾と個人情報の公開可否を確認してから公開してください。
