東部地域 暮らしの案内

スマホのホーム画面に
追加しよう

アイコンを押すだけで、地域の情報を開けます。Android・iPhoneの両方に対応しています。追加せず、今のまま使うこともできます。

お使いのスマホに合わせて、下の手順をお試しください。

使い方PDFを開く（6ページ・画像付き）

PDFは保存・印刷して、ご家族や地域の方と一緒に確認できます。

Androidの場合

  1. Chromeでこのサイトを開く
    LINEなどの中で開いているときは、Chromeで開き直します。
  2. 右上の「︙」を押す
    ブラウザのメニューを開きます。
  3. 「ホーム画面に追加」を選ぶ
    「アプリをインストール」と表示される場合もあります。
  4. 「インストール」または「追加」を押す
    ホーム画面に「東部地域」のアイコンが出たら完了です。

上に「ホーム画面に追加する」ボタンが出ている場合は、そのボタンからも追加できます。

iPhoneの場合

  1. Safariでこのサイトを開く
    LINEなどの中で開いているときは、Safariで開き直します。
  2. 共有ボタン「□↑」を押す
    共有ボタンが見つからない場合は、メニューの中もご確認ください。
  3. 「ホーム画面に追加」を選ぶ
    見つからないときは、共有メニューを下へ動かします。「アクションを編集」から追加できる場合もあります。
  4. 「追加」を押す
    「Webアプリとして開く」が表示されたらオンにします。ホーム画面の「東部地域」を押して使います。

追加したあとの使い方

HOME：目的から探す・今月の予定を見る。
7地区：お住まいの地区から探す。
通いの場：体操やおしゃべりの場所を検索。
地域マップ：場所を確認し、Googleマップへ。
タイムライン：試用登録後に写真やひとことを保存。

文字は画面上の「大きく」で読みやすくできます。

知っておいてほしいこと

最初はインターネットにつないで開いてください。通信が切れた場合は保存済みの画面を表示します。最新情報・外部の地図・未保存のページには通信が必要です。

呼び名・地区・写真の投稿は、現在このブラウザ内での保存です。ほかの方への共有や、オンライン会員認証は準備中です。Safariと追加したアプリで保存内容が分かれる場合があります。

「新しい版があります」と表示されたら、入力を保存してから「更新する」を押してください。予定の変更は、参加前に各窓口へご確認ください。

メニューの名前や位置は、機種・OS・ブラウザによって異なります。
